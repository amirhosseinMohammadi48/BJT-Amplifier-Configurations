# BJT Amplifier Configurations

## Overview
This project focuses on the analysis and simulation of BJT amplifier circuits using PSpice. Three basic amplifier configurations are investigated, followed by a combined circuit incorporating these stages.

## Objectives
- Analyze the characteristics of common-base (CB), common-emitter (CE), and common-collector (CC) amplifier configurations.
- Simulate the circuits using PSpice.
- Examine and compare simulation results with theoretical expectations.
- Investigate the characteristics and performance of a combined amplifier circuit.

## Project Structure
The project files are provided in a compressed ZIP archive containing the simulation files for the different circuit configurations.

## Tools
- **PSpice:** Circuit simulation and analysis

## Key Topics
- BJT amplifier configurations
- Voltage gain and input resistance
- Circuit simulation and theoretical analysis
- Multistage amplifier circuits

## Notes
The ZIP archive contains the project simulation files. Extract the archive to access the individual files.
